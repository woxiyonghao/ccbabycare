萌宝喂养日记（ccbabycare）

面向 0–3 岁宝宝家庭的本地离线极速记录与成长管理工具。将纸质手绘日记本的温馨直观与原生数字化的自动化洞察深度融合，专为夜间单手操作与全家轮班照护量身打造。

产品定位与价值 日记本参考与标准 八大核心功能 交互演示与模拟 技术架构与工程分层 版本规划与路线
Core Value Proposition

为什么打造「萌宝喂养日记」？

🍼

单手 3 秒极速记录

凌晨抱娃喂奶场景，单手大按钮交互，≤ 3次点击完成一次配方奶/亲喂记录。自动计算与上次喂养间隔时间，告别手忙脚乱。

🔒

100% 离线沙盒存储

无注册、无登录、无任何网络请求。所有照片与生长数据仅存储在手机应用沙盒内，杜绝隐私泄露，不申请通讯录/位置等任何敏感权限。

📖

纸质手绘日记本数字化

还原纸质喂养手帐的温润奶油风。涵盖“照护人身份交接（老人/月嫂/父母）”、“月计划作息”、“每月养娃花销记账”与“父母寄语”。

Functional Modules

系统功能规格矩阵

👶

1. 宝宝多档案管理

支持多个宝宝一键切换；输入生日自动精确计算“X月X天”；支持宝宝专属萌趣头像与基础体征档案。

🍼

2. 极速喂养记录 (核心)

支持配方奶（段位1~4段、冲调水粉比、实际喂入奶量）、母乳亲喂（单/双侧计时）、母乳瓶喂、饮水及辅食过敏标记。支持“再来一次”秒级复制。

💩

3. 排便排尿健康观察

快速记录嘘嘘/便便/混合。内置 5 种便便性状、6 种便便颜色选择，支持“异常便便”高亮红点标记，就医时一键陈述。

🌙

4. 睡眠作息管理

支持“一键开始/结束”实时计时，或手动快速输入时段；自动区分白天小睡与夜间睡眠，汇总日均总时长与夜醒频次。

💉

5. 国家免疫规划疫苗

内置 0~6 岁国家免疫规划常用疫苗库（乙肝、卡介苗、脊灰、百白破等），支持分区已接种与待接种，提供离线本地提醒。

📈

6. 2026标准生长曲线

身高、体重、头围随月龄动态折线图，叠加国家 2026 最新标准参考区间，生长发育是否达标一清二楚。

💰

7. 每月花销与日记手帐

源自手绘日记本特色：奶粉/尿不湿/衣物玩具/医疗分类记账；月度里程碑照片墙与父母温馨寄语沉淀。

💾

8. 离线全量数据备份/导出

一键将全量记录导出为 JSON 或 Excel/CSV 文件，调用系统原生分享与文件面板，免权限安全迁移。

✨

9. Lottie 灵动微动效

引入 HarmonyOS 原生 @ohos/lottie 库，将喝奶、睡眠、便便、疫苗等日常记录赋予生命力，体验温馨灵动。

System Architecture

HarmonyOS 原生架构与目录分层

架构层次 工程目录路径 核心职责与设计说明
展示层 (UI) entry/src/main/ets/pages/
• home/, record/, diary/, statistics/, profile/		 声明式 ArkTS UI，采用 5 栏底部 Tab 导航结构；配合手绘温润色调、圆角卡片与 Lottie 动效。
通用组件层 entry/src/main/ets/common/components/ 极速记录浮动底栏 (QuickRecordBar)、照护人切换选择器 (CaregiverPicker)、今日时间轴记录卡 (TimelineCard) 等复用组件。
业务逻辑层 entry/src/main/ets/common/utils/
• GrowthEvaluator.ets
• DateUtil.ets		 2026儿童生长标准评测引擎（偏低/正常/偏高计算）、喂养间隔自动倒计时、月龄高精度推导。
数据持久层 entry/src/main/ets/common/database/
• DatabaseHelper.ets
• BabyTable, RecordTable		 基于 HarmonyOS 原生 relationalStore (RdbStore) 本地 SQLite 存储，单条记录入库 < 50ms。
备份与迁移层 entry/src/main/ets/common/utils/BackupExporter.ets 全量数据 JSON/CSV 结构化导出与恢复，走系统原生 FilePicker 机制，零敏感权限申请。
