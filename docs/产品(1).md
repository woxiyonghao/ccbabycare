## 0. 文档目的

本文档定义"宝宝喂养日记"产品的需求范围、功能规格、数据模型、交互流程与非功能要求，供设计、开发、测试等角色理解并实现产品。

产品灵感来源于市面上的**纸质宝宝喂养记录本**（如天猫婴儿喂养日记本）：它通过表格记录宝宝每天的吃奶、辅食、睡眠、排便、疫苗与成长数据。本产品将其**数字化、自动化、可检索**，同时保留纸质记录本的直观与简洁。

## 1. 产品概述

### 1.1 产品定位

一款面向 0–3 岁宝宝家长的**本地离线喂养与成长记录工具**。帮助家长随时随地、用最短操作记录宝宝的吃奶、吃饭、排便、睡眠、疫苗接种与生长发育，并通过可视化图表掌握宝宝的作息规律与健康趋势。

### 1.2 核心价值

1. **极简记录**：单手、3 秒内完成一次记录，适配忙乱的育儿场景。
2. **数据私密**：数据仅存储在用户设备本地，**完全离线运行，无需联网，无需注册登录**，杜绝隐私泄露。
3. **自动化洞察**：自动计算两次喂奶间隔、全天总量、排便次数、睡眠时长，生成成长曲线。
4. **结构化喂养档案**：支持记录第几期（段位）、冲调勺数、水量与喂食量，告别手写混乱。
5. **疫苗管理**：记录疫苗名称、接种日期、针次、接种机构，支持本地接种提醒。

### 1.3 产品边界（非目标）

- 不提供账号、登录、注册、会员体系。
- 不依赖网络、云同步、社交分享（可选通过文件导出/导入实现"迁移"而非"云同步"）。
- 不提供 AI 诊断、医疗建议类功能。
- 不接入电商、广告；不采集用户数据。
- **不申请任何手机系统敏感权限**：不申请通讯录、定位、相机、麦克风、电话、短信、存储等权限；数据仅写入应用自身的本地沙盒目录。

## 2. 用户与场景

### 2.1 目标用户

- 新手妈妈 / 新手爸爸（主力，0–1 岁阶段）。
- 月子中心护理人员、月嫂、育儿嫂。
- 有记录习惯、希望与其他照护者交接信息的长辈 / 保姆。
- 二胎家庭或需要同时管理多个宝宝的家长。

### 2.2 典型使用场景

- **场景 A（夜间喂奶）**：凌晨 3 点喂完奶，家长单手打开 App 点击"配方奶"，选择已存好的奶粉，录入奶量 120ml，完成。系统自动记录时间并计算与上次喂奶间隔。
- **场景 B（排便观察）**：发现宝宝大便异常，家长快速记录便便性状、颜色，方便后续就医时向医生陈述。
- **场景 C（疫苗日）**：接种前查看该疫苗的既往针次与下次接种时间；接种后录入疫苗名称、针次、批号与不良反应。
- **场景 D（体检看趋势）**：带宝宝体检后录入身高、体重、头围，查看生长曲线，判断发育趋势。
- **场景 E（多照护者交接）**：在无网络、甚至手机无信号的情况下，仍可完整记录，照护者之间通过本机数据了解宝宝全天情况。

## 3. 产品信息架构

产品以"**快速记录 + 时间轴 + 统计**"为核心，采用底部导航结构。

```text
宝宝喂养日记
├── 首页（今日概览 / 快速记录 / 时间轴）
├── 记录（核心：新增喂养、排便、睡眠、疫苗、成长）
├── 统计（趋势图、汇总报表、周期对比）
├── 档案（宝宝管理、奶粉库、疫苗计划、提醒设置）
└── 数据（导出 / 备份 / 导入 / 关于）
```

## 4. 功能需求

> 优先级：P0（必须，MVP）/ P1（重要，V1.1）/ P2（增强，V1.2+）

### 4.1 宝宝档案管理（P0）

**需求描述**：支持创建多个宝宝，每个宝宝拥有独立档案与数据。

**字段**：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| 宝宝昵称 | 文本 | 是 | 用于展示与快捷区分 |
| 生日 | 日期 | 是 | 用于自动计算月龄 |
| 性别 | 单选 | 否 | 男 / 女 |
| 出生体重 | 数值 kg | 否 | 初始生长数据 |
| 出生身长 | 数值 cm | 否 | 初始生长数据 |
| 血型 | 单选 | 否 | A/B/AB/O/未知 |
| 头像 | 图片 | 否 | 系统图片选择器或预设头像（见 4.13 权限说明） |
| 备注 | 文本 | 否 | 过敏、注意事项等 |

**验收标准**

- 可新增 / 编辑 / 删除宝宝（删除需二次确认并提示数据一并删除）。
- 切换宝宝后，所有页面数据随之切换。
- 自动按生日计算"X 月 X 天"，并随日期自动更新。

### 4.2 喂养记录（P0，核心）

**需求描述**：记录宝宝的每一次喂养，支持多种喂养方式。

**喂养方式**：

1. **母乳亲喂**
2. **母乳瓶喂**
3. **配方奶**
4. **饮水**
5. **辅食**

#### 4.2.1 通用字段

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| **喂食时间** | 日期时间 | 是 | 默认当前时间，可改 |
| 方式 | 单选 | 是 | 上述五种之一 |
| **喂食量** | 数值 | 是 | 各方式对应的量，单位随方式而定（亲喂=时长、配方奶/瓶喂=ml、辅食=g/勺/碗） |
| 备注 | 文本 | 否 | 拍嗝、呕吐、哭闹等 |

> 设计要点：**喂食时间**与**喂食量**为每条喂养记录的强制标注内容，在时间轴、今日概览与统计中始终突出展示。

#### 4.2.2 母乳亲喂专属字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| 侧别 | 单选 | 左 / 右 / 双侧 |
| 单侧时长 | 分钟 | 每侧时长 |
| **喂食量（总时长）** | 分钟 | 即该次亲喂的喂食量，可自动累加 |
| 吮吸情况 | 单选 | 正常 / 偏弱 / 急促 |
| 奶阵次数（可选） | 数值 | 备注用 |

#### 4.2.3 配方奶专属字段（重点）

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| **第几期（段位）** | 单选 | 是 | 1段 / 2段 / 3段 / 4段（或 0–6月/6–12月/1–3岁） |
| 冲调勺数 | 数值 | 可选 | 单位：平勺 |
| 水量 | 数值 ml | 可选 | 冲调用水 |
| **喂食量（总奶量）** | 数值 ml | 是 | 实际喂入量 |

> 设计要点：**喂食量（总奶量）**为核心必填项；"冲调勺数 + 水量"为用户可选的高级项，支持按配比自动换算。产品**不记录奶粉品牌/系列**，仅保留"段位"用于区分。

#### 4.2.4 母乳瓶喂

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| **喂食量（瓶喂奶量）** | 数值 ml | 实际喂入量 |
| 奶源 | 单选 | 冷藏 / 冷冻 / 亲喂后泵出 |
| 提前准备时间 | 时间 | 如解冻时间 |

#### 4.2.5 辅食记录

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| 食物 | 文本/选择 | 辅食名称，可多选 |
| 食材列表 | 文本 | 如"米粉、南瓜、蛋黄" |
| **喂食量（分量）** | 数值 | g / 勺 / 碗 |
| 是否新添加 | 布尔 | 标记首次尝试（过敏观察） |
| 过敏反应 | 文本 | 可选 |

**验收标准**

- 一次记录默认耗时 ≤ 3 次点击。
- 记录成功后自动加入当日时间轴，并更新"距上次喂奶间隔"。
- 可从"奶粉库"快速选择常用奶粉（段位 + 常用量），无需重复输入。
- 支持快速复制上一次同类记录（"再来一次"）。

### 4.6 成长记录与生长曲线（P1）

**需求描述**：记录身高、体重、头围，并**内置中国身高体重标准参考**（《7 岁以下儿童生长发育参照标准》WS/T 423—2022），自动比对宝宝的生长发育百分位/区间。

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| 测量日期 | 日期 | 是 | |
| 身高 | 数值 cm | 是 | |
| 体重 | 数值 kg | 是 | |
| 头围 | 数值 cm | 否 | |
| 测量方式 | 文本 | 否 | 家庭 / 医院 / 社区 |
| 备注 | 文本 | 否 | |

#### 4.6.1 身高体重标准参考

**需求描述**：内置离线可用的儿童生长标准参考表，用于判断身高、体重是否处于正常范围。

| 项目 | 说明 |
| --- | --- |
| 参考标准 | 内置《7 岁以下儿童生长发育参照标准》WS/T 423—2022（默认）；可选择性加载 WHO 标准作对比（默认关闭） |
| 适用范围 | 0–7 岁（按性别 + 月龄/年龄匹配） |
| 标准维度 | 按性别 + 月龄给出身高、体重（头围可选）的中位数与正常范围（如 P3–P97 / ±2SD） |
| 比对展示 | 录入后自动显示："当前身高/体重处于正常范围内 / 偏低 / 偏高"及参考区间 |
| 区间划分 | P3 / P15 / P50 / P85 / P97（或 -2SD / -1SD / 中位 / +1SD / +2SD） |
| 数据来源说明 | 标准参考仅作成长对照，不作为诊断依据，界面需明确标注 |

**验收标准**

- 录入身高/体重后，无需联网即可给出参考区间与百分位提示。
- 可按性别与月龄自动匹配对应标准表。
- 生长曲线图可叠加标准参考曲线（P50 / P3 / P97）进行对照。
- 默认采用中国标准；切换 WHO 标准仅作对比，默认不启用。

**验收标准**

- 自动生成身高 / 体重 / 头围随月龄变化的折线图，可叠加中国标准（WS/T 423—2022）参照曲线（P50 / P3 / P97）。

### 4.7 首页 / 今日概览（P0）

**需求描述**：第一时间呈现宝宝今天的核心情况，并提供快速记录入口。

**展示内容**

- 宝宝信息卡片（昵称 + 月龄 + 当前体重）。
- 今日关键指标：喂奶次数与总量、排尿次数、便便次数、总睡眠时长、距上次喂奶间隔。
- 今日时间轴：按时间倒序展示所有记录（喂养、排便、睡眠、疫苗、成长）。
- 待办提醒：今日待接种疫苗、成长测量提醒。
- 快捷记录按钮组：配方奶 / 亲喂 / 排便 / 睡眠 / 辅食。

**验收标准**

- 打开即是最新状态，无加载等待。
- 快捷按钮一键进入对应记录表单，默认时间 = 当前时间。

### 4.8 时间轴与日历视图（P1）

- **日视图**：完整展示某一天的记录流水。
- **周 / 月视图**：以日历格展示记录密度（如某日喂奶次数、便便次数红点），支持点击进入日视图。
- 支持按记录类型筛选（只看喂养 / 只看排便）。

---

### 4.9 统计与趋势（P1）

**统计维度**

- 喂养：近 7/30 天日均喂养次数、总奶量、两种喂养方式占比、平均间隔。
- 睡眠：日均总睡眠时长、夜醒次数。
- 排便：日均次数、异常次数占比。
- 成长：生长曲线、月龄体重/身高百分位参考。

**交互**

- 图表支持切换周期（日 / 周 / 月）。
- 关键指标可一键分享为图片导出（本地生成，不上传）。

### 4.11 数据导出 / 备份 / 导入（P0）

**需求描述**：由于产品无账号无云同步，数据迁移与备份通过本地文件实现。

- **导出**：将全部数据导出为 CSV / Excel / JSON 文件，通过系统"分享/存储"面板保存到设备本地（可发送至微信/邮件作为备份）。
- **备份**：一键生成备份包（含数据库），便于恢复。
- **导入 / 恢复**：从备份包恢复数据（支持追加或覆盖）。
- **防误删**：删除数据需二次确认；提供回收站或"撤销"。

**验收标准**

- 导出文件可被常见表格软件打开。
- 备份包可恢复到同设备或新设备（离线完成）。
- 导出/导入走系统文件选择与分享能力，**不申请存储权限**。

---

### 4.12 本地提醒（P1）

- 利用系统本地通知（无需网络）实现：喂奶间隔过长提示（可关闭）、疫苗下次接种提醒、成长测量提醒。
- 提醒开关、频率、时间均可自定义。
- **权限策略**：本地提醒为可选项。若平台要求"通知权限"授权，则不强制索取；未授权时降级为**应用内提醒页 / 今日待办**，核心记录功能不受任何影响。

### 4.13 权限最小化原则（全局约束）

**需求描述**：产品原则上**不申请任何手机系统权限**，最大限度降低隐私顾虑与授权门槛。

| 功能 | 处理方式 |
| --- | --- |
| 相机拍摄 | 不支持；不做入口 |
| 相册选头像 | 使用系统标准图片选择器（Picker），或直接用预设可爱头像 / 首字母头像 |
| 定位 | 不支持；不使用位置信息 |
| 通讯录 | 不支持；不使用联系人 |
| 麦克风 / 录音 | 不支持 |
| 电话 / 短信 | 不支持 |
| 外部存储 | 不支持；数据仅在应用私有沙盒，导出走系统分享/文件面板 |
| 网络 | 不支持；完全离线 |
| 通知（可选） | 仅提醒功能用，可关闭；不授权则用应用内待办替代 |

**验收标准**

- 首次安装、运行、使用全流程中，不弹出任何系统权限请求弹窗（通知权限除外，且默认可跳过）。
- 关闭权限或拒绝授权后，产品全部核心记录功能仍可正常使用。

| 类别 | 需求 |

## 6. 数据模型（核心实体）

```text
Baby（宝宝）
  └─ FeedingRecord（喂养记录，含配方奶/亲喂/瓶喂/辅食）
  └─ EliminationRecord（排便/排尿）
  └─ SleepRecord（睡眠）
  └─ VaccineRecord（疫苗）
  └─ GrowthRecord（成长）
  └─ FormulaProfile（奶粉库）
  └─ Reminder（本地提醒）
```

### 实体关系

- 一个 `Baby` 拥有多个各类记录（1:N）。
- `FeedingRecord` 关联可选 `FormulaProfile`（配方奶记录使用）。
- 所有记录带 `baby_id`、`record_time`、`created_at` 字段。

### 数据存储建议

- 移动端本地数据库：`SQLite`（Room / CoreData / 底层封装）。
- Web/PWA 版本：`IndexedDB`。
- 图片（如头像）存储于应用沙盒本地文件。

## 7. 关键交互流程

### 7.1 快速记录（配方奶）

1. 首页点击"配方奶"快捷按钮。
2. 选择奶粉（奶粉库 / 快速新增）。
3. 默认自动填充：段位 + 常用量；用户可调整勺数、水量、总奶量。
4. 点击"记录"，回到首页，时间轴顶部出现该条记录。

### 7.2 开始 → 结束睡眠

1. 首页点击"睡眠"。
2. 点击"开始"，记录当前时间；页面显示计时中。
3. 再次点击"结束"，自动生成时长并保存。

### 7.3 接种疫苗 + 提醒

1. 档案页进入"疫苗"。
2. 选择疫苗名称，录入日期、针次、机构。
3. 开启"下次接种提醒"，选择时间，保存。
4. 到点触发本地通知。

## 11. 风险与应对

| 风险 | 应对 |
| --- | --- |
| 设备丢失 / 更换导致数据丢失 | 提供一键备份到文件；引导用户定期导出 |
| 本地加密影响性能 | 提供可选的加密开关，默认不加密 |
| 无账号导致无法跨设备 | 通过导入/导出迁移；未来可选局域网协同 |
| 记录字段过于复杂 | 默认隐藏高级字段，一键展开；预置常用输入 |
| 疫苗信息更新滞后 | 预置常用疫苗 + 支持自定义，注明"仅供参考" |
